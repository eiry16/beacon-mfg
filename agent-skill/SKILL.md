# BeaconMFG 薄框架检索 Skill

## 这是什么（薄框架）

一个**只装指令、不装数据**的检索技能。外部 Agent 从 git 安装本目录后，手里只有：

- 本 `SKILL.md`（协议与流程）
- `client_search.py`（按需拉取封装）

**不需要 clone 整个仓库的 `data/`**（那有上百 MB，且每天刷新会过期）。
名录数据在**查询时才按国标码从公开 CDN 拉取**，平均每次查询的传输量远小于整个仓库。

> 与本仓库根目录 `SKILL.md`（`name: beacon-mfg`）的区别：根 SKILL 假设整库已检出、
> 直接读本地文件；**本薄框架是给「只装了技能、没装数据」的外部 Agent 用的**，
> 一切走 CDN 按需。两者检索结果同源、口径一致。

## 边界（强制）

- 只提供公开联系方式与基本信息，**不参与**询价/下单/交易。
- **不**对任何企业做推荐评级；用户要「最好的一家」→ 说明「按契合度排序，请自行核实」。
- 不编造价格、交期、产能；数据里没有的就不说。

## 权限与网络

- **所需权限**：仅「网络访问」。本技能**不**读取、不上传用户本机任何文件；所有对外请求都是「拉取公开名录数据」。
- **请求域名与用途**：仅访问本项目的公开只读 CDN（无需任何密钥），主源为 `https://beacon-mfg.pages.dev`；同源公共镜像由 `client_search.py` 自动选择兜底。
- 每次查询只拉取命中的那部分数据，不下全量。

## 数据来源与隐私

- **数据来源**：全部为**公开**经营信息（公开地图 POI / 工商公开目录），不含任何非公开抓取。
- **不捆绑 PII**：本技能包内**不含**任何企业联系方式或个人信息；联系方式由云端按需求提供，且仓库快照已隐私处理（`138****0000` 形态）。
- **隐私与申诉**：企业若需更正或删除自身信息，可通过 GitHub Issue 提交申诉，项目方按 CC BY 4.0 与数据许可处理。
- **许可**：代码 MIT、数据 CC BY 4.0（允许商用与再分发，须保留来源署名）。下游使用请注明「数据来源：BeaconMFG 供应商灯塔」。
- **合规边界**：仅提供公开名录检索，不参与交易、不做评级、不编造字段；法人个人信息一律不返回。

## 查询流程（先澄清，再拉取）

**第 0 步：澄清需求**。用户只说「找个做精密件的」就先问清：

- **供应商类型** → 转成国标码（见下）
- **地域** → 城市名（如「上海」「宁波」）

需求明确前**不要盲拉**——薄框架的省流就靠这一步。

**第 1 步：类型 → 国标码**（三种来源，强度递减）：

1. 数字码直用（`3525` 小类 / `34` 大类 / `C` 门类）
2. 采购词查**别名表**（如 `CNC加工`→3484、`精密机械加工`→3484/3311、`PCB`→3989）
3. 行业名查 GB/T 4754 全量标准（如「模具制造」→3525）

> `client_search.py` 自动走这条解析链；解析不出会如实告诉用户，不静默放宽。

**第 2 步：按国标码拉取命中数据**（由脚本完成，无需手工拼路径）。

**第 3 步：客户端过滤 + 排序**：

- 地域：按记录内的城市字段精确匹配（去「省/市」后缀）
- 工艺/材料：按工艺、材料字段收敛
- 契合度排序：**关键词命中 > 资料完整度 > 有电话 > 凭证等级**

**第 4 步：显示前 N + 按需拉详情**。只把排前几家呈现给用户；
用户点开某家 → 才取该企业的完整档案（或该企业的 L2 自述）。

## 客户端用法

```bash
# 国标码 + 城市
python client_search.py --industry 3525 --city 宁波 --limit 5
# 采购词（自动解析成国标码）+ 城市
python client_search.py --keyword "CNC加工" --city 深圳
# 工艺/材料收敛
python client_search.py --industry 3525 --city 宁波 --proc cnc_milling --mat 铝合金6061
# 拉某家完整档案(L2)
python client_search.py --industry 3525 --detail CN-MFG-0001234
# 离线读本地仓库（需 --repo 指向仓库根）
python client_search.py --industry 3525 --city 宁波 --local --repo /path/to/beacon-mfg
```

脚本自带：请求头伪装（保证 CDN 可访问）、缓存（二次查询零下载）、主源失败自动切镜像、
结尾打印「本次传输 vs 全量 clone」证明按需省流。

## 覆盖范围（7 个国标门类）

C 制造业 / F 批发零售 / H 住宿餐饮 / I 信息技术 / M 科研技术 / O 居民服务 / R 文体娱乐。
具体家数与城市数以仓库主页公布的最新数字为准；某门类查不到就如实说明覆盖边界，别从别的门类凑近似结果。

## 呈现要求（强制）

- 返回 2–3 家最匹配，必须标注「数据来自公开渠道 + 核实日期」
- 联系方式完整展示（座机/400/手机）；缺失显示「待核实」，不编造
- 用户要法人个人信息 → 拒绝
- 行业未知时不替它猜；批发/贸易商要提示「非生产」；未核验的凭证等级如实标注「未经平台核验」

## 数据说明

- 当前约 5.2 万家中英文名录；已核实电话与待核实电话均为真实企业 POI，一并保留返回
- 覆盖长三角 + 珠三角为主的多个城市
- 待核实记录也是真实企业，检索时保留并返回，不丢弃
- 企业要求更正/删除联系方式 → 引导其通过 GitHub Issue 提交
