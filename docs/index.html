How an agent uses it

# git clone + load SKILL_EN.md, then ask your agent:
"Find a CNC machining shop near Shenzhen that accepts small batches"

# or use the CLI directly:
$ python scripts/query.py --keyword "CNC Machining" --city Shenzhen --en --limit 5
→ Company: Shenzhen ... Co., Ltd. (Guangdong · Shenzhen)
→ Products: CNC Machining
→ Phone: 135****9722 (masked) / 0769-88007830 (landline)

Design principles

✅ Compliance-first

Public info only. Personal mobiles are masked (1XX****XXXX); full numbers are never stored — companies submit their own business contacts via a future claim mechanism (lawful authorization). No scraping of B2B platforms.

✅ Info-only, open data

No quoting, no transactions, no ratings. Every record carries source + verification date. Code MIT, data CC BY-NC. Free forever — data is the moat, position is the asset.

✅ Zero-dependency tooling

Fetch ( public API) → mask → validate → translate → push. All Python stdlib, one-click GUI included. Quota-aware ( ~100 req/day for personal devs).

✅ Built for the agent era

Bilingual datasets (data/suppliers + data/en), SKILL.md / SKILL_EN.md, deterministic JSON schema, CI validation on every PR. Sourcing collapses from days to minutes.

Contribute

Corrections, new categories, company claims — all welcome via GitHub Issues / PRs. Data verification is our #1 need.
