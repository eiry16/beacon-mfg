## 正文

做制造业采购的朋友都知道找供应商有多痛苦：百度搜出来全是广告，1688 上真假难辨，跑展会又贵又慢。我做了个开源项目 —— **BeaconMFG（供应商灯塔）**，把中国的制造业供应商按"产品关键词"整理成结构化名录，让 AI Agent 直接检索。

**现状**：
- 1,773 家供应商，8 大品类（CNC 加工 / 钣金冲压 / 注塑 / 压铸 / 电子元器件 / 表面处理 / 标准件 / 原材料）
- 覆盖深圳、东莞、苏州、宁波、无锡、佛山
- 中英双语（英文镜像自动翻译，给海外买家用 —— 相当于"24 小时免费的线上广交会"）
- 每条记录：公司名、主营关键词、地区、公开电话、数据来源、核实日期

**Agent 怎么用**（无需 API Key）：
```
git clone https://github.com/eiry16/beacon-mfg
# 加载 SKILL.md 后直接问：
# "找深圳能接小批量 CNC 加工的厂"
# 或命令行：
python scripts/query.py --keyword "CNC加工" --city 深圳 --limit 5
```

**几个设计选择，欢迎拍砖**：
1. **合规优先**：只收录公开信息；个人手机号一律脱敏（135****9722），完整号只在"企业认领"时由企业自己提交 —— 不碰 1688/企查查等平台的爬取
2. **只做信息层**：不参与询价、交易、评级，纯粹把"找供应商"这件事做干净
3. **零依赖工具链**：抓取（高德公开 API）→ 脱敏 → 校验 → 翻译 → 推送，全 Python 标准库，还带一键 GUI
