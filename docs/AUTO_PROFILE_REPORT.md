## 分层存储（2026-09-07 拆分）

**Git 仓库只放引流层，能力卡与采集引擎全部私有。**

| 层 | 路径 | 进 Git | 说明 |
|---|---|---|---|
| L0 指纹 | `skills/registry/fingerprint/*.jsonl` | ✅ | 客户 Agent 全量扫这层做初筛，约 700KB |
| L1 能力卡 | `skills/vendors/*/capability.json` | ❌ | 走云端按需拉取 |
| L2 自述 | `skills/vendors/*/SKILL.md` | ❌ | 走云端按需拉取 |
| 协议规范 | `skills/schema/`、`skills/profiles/`、`TEMPLATE.md` | ✅ | 引流的一部分，让人照着做 |
| 样板 | `skills/vendors/CN-MFG-0000005/` | ✅ | 唯一进 Git 的完整卡片，展示"标准长什么样" |
| 采集引擎 | `scripts/` | ❌ | 私有资产，已在 `.gitignore` |

理由：2700 家 ×（SKILL.md + capability.json）≈ 25MB 且持续增长。客户 Agent 只需 L0 指纹
即可完成 95% 的初筛淘汰，命中后才调 API 取 L1/L2。
