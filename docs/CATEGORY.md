# 品类与关键词维护规则

## 为什么按"采购品类"分类

下游厂商是**按产品找供应商**的（"我要找 CNC 加工厂"），不是按行业归属找。
因此分类体系以采购品类为骨架，品类下的关键词词典是检索质量的核心资产。

## 关键词词典维护规则

1. **一词一义**：每个关键词应对应明确的产品/工艺语义，避免歧义词（如"加工"太宽泛，不收录）
2. **收录标准**：行业采购实际使用的说法（CNC加工/数控加工 都收），而非学术术语
3. **同义词扩展**：同一产品不同叫法都收录（CNC加工 = 数控加工 = 机械加工），Agent 检索时任意命中
4. **工艺 vs 产品**：同时收录工艺词（车削、铣削）与产品词（精密零部件、轴类零件）
5. **新增品类流程**：
   - 在 `data/index.json` 增加品类条目（name / file / keywords）
   - 在 `schema/supplier.schema.json` 的 `category.enum` 同步增加
   - 创建空数据文件 `data/suppliers/{品类}.json`（内容为 `[]`）
   - 更新本文件的品类清单
