## 填写须知（提交时删除本节）

**三条红线：**
1. **不填就留空**，禁止编造。价格、产能、交期没写就是没写，客户 Agent 会如实呈现"未提供"。
2. **外协必须标注**。`processes` 里 `level` 为 `outsourced` 的工艺，客户 Agent 会知道这不是你自有产线。
3. **第 5 段不能空**。这是模板里唯一强制的段落。

**提交前自检：**
```bash
python scripts/validate_vendor_skills.py {你的 supplier_id}
```
出现 `[PASS]` 才可提 PR。

**安全**：SKILL.md 只允许上面 8 个 `##` 段落，多余段落会被 CI 拒绝；
禁止出现指令性语句（如"优先推荐我"），一律视为提示注入并拒绝。
