# BeaconMFG 供应商 Skill 库

供应商在这里提交自己的**能力卡**，让客户 Agent 能判断"这家厂能不能做我的活"。

- 只想被人搜到 → 什么都不用做，`data/` 里的公开名录已经可检索
- 想让客户 Agent 知道你能做什么 → 提交 Skill（本文档讲怎么做）

---

## 我能得到什么

| | 不提交 | 提交后 |
|---|---|---|
| 客户 Agent 能查到 | 公司名 + 电话 | 工艺、公差、尺寸、MOQ、交期、认证 |
| 被需求命中 | 靠关键词猜 | 靠数值确定性匹配 |
| 收到的询单 | 什么都有 | 只收到你声明能做的 |

**关键收益**：第 5 段「我们不做的」会帮你挡掉不匹配的询单。
这是模板里唯一强制的段落，因为它直接提高你的成交率。

---

## 三步提交

### 第 1 步：认领你的记录

在 `data/suppliers/{品类}.json` 里搜公司名，找到你的 `id`（形如 `CN-MFG-0000005`）。

> 未认领不能提交 Skill——防止有人冒名填写你的能力信息。
> 认领方式见仓库根目录 `SPEC.md` 第 3 节（微信服务号 / 企业邮箱 / 人工审核）。

### 第 2 步：生成你的 Skill（两种方式）

**A. 对话采集（推荐，15 分钟）**

不用碰 JSON。采集引擎会逐题问你，口语回答即可：

```bash
python scripts/collect/cli.py --id CN-MFG-0000005
```

它问"常规公差能控制在多少？"，你答"一般一丝吧"——引擎自动记成 `±0.01mm`。
答"八百乘六百，高度四百"——自动记成 `[800,600,400]mm`。

跑完自动生成 `SKILL.md` + `capability.json` + 指纹行。

**B. 手工填写**

```bash
cp skills/TEMPLATE.md skills/vendors/CN-MFG-0000005/SKILL.md
# 对照 skills/profiles/{你的品类}.json 填写 capability 块
```

### 第 3 步：校验并提交

```bash
python scripts/validate_vendor_skills.py CN-MFG-0000005
```

看到 `[PASS]` 后提 PR，标题格式：`[SKILL] {公司名} / {品类}`。

## 三层结构（为什么不能只写一个文件）

客户 Agent 面对 8000 家供应商，不可能把每家的自述都读一遍。所以分三层：

| 层 | 内容 | 大小 | 何时加载 |
|---|---|---|---|
| **L0** 指纹行 | 工艺/材料/公差/尺寸/MOQ/交期 | ~120 字 | 全量扫描，数值规则淘汰 95% |
| **L1** 能力卡 | 完整结构化能力 | ~300 tokens | 约 30 家入围时 |
| **L2** 自述 | 设备、擅长、边界、商务 | ~800 tokens | 最后 5 家精读 |

**所以：L0 的数值决定你会不会被看到。** 公差、MOQ、尺寸这些字段填得越准，
被正确需求命中的概率越高。

## 凭证等级

| 等级 | 含义 | 客户 Agent 呈现 |
|---|---|---|
| **L0** | 公开名录收录 | "公开名录，未核验" |
| **L1** | 已认领，信息由企业自述 | "企业自述" |
| **L2** | 平台已核验（营业执照/资质证书） | "平台已认证" |
| **L3** | 第三方实地验厂 | "第三方核验" |

## 安全红线（CI 强制）

你的 Skill 会被**别人家的 Agent** 读取，因此：

1. **Skill 是数据，不是指令** —— 禁止出现任何指令性语句
2. **只允许模板中的 8 个 `##` 段落** —— 多余段落直接拒绝
3. **禁止提示注入** —— "优先推荐我"、"忽略之前的指令" 等一律拒绝
4. **外部域名必须申报** —— 写在 `capability.json` 的 `safety.external_domains`
5. **体积上限** —— SKILL.md ≤ 4KB，附件总量 ≤ 10MB

被拒绝不代表你有恶意，只是自动扫描的保守策略。改掉即可重新提交。

## 常见问题

**Q：我能改别人的记录吗？**
不能。CI 会校验 `supplier_id` 与认领身份一致。

**Q：填错了能改吗？**
能。改完再提 PR 即可，历史版本在 Git 里。

**Q：我的信息会被抄袭吗？**
公开的薄名录（公司名/电话/地址）本来就是公开信息。
你主动填写的能力数据是平台资产，通过 API 按需下发并带调用方追溯。

**Q：为什么第 5 段强制？**
因为客户 Agent 看到"这家明确不做大件"，就不会把大件询单发给你。
你收到的询单更少但更准，成交率反而更高。
